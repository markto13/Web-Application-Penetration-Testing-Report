# Web-Application-Penetration-Testing-Report
Web Application Penetration Testing Report
A web application vulnerability assessment and penetration test conducted against a vulnerable lab environment (ITP425.org), covering reconnaissance, exploitation, and remediation guidance across seven OWASP Top 10 categories.

`Web Application Penetration Testing Report.docx` — full penetration testing report

Overview
This project outlines a web application security assessment including:
- Automated and manual vulnerability scanning (Nexpose, Nikto, Burp Suite)
- Exploitation of critical and high-risk findings, including path traversal, Heartbleed, broken authentication, local file inclusion, OS command injection, and SSRF
- Risk scoring using CVSS v3.1
- Root cause analysis and remediation recommendations for each finding
